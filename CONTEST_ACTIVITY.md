# Coding Contest Activity

## Objective

Participate in a live or virtual coding contest and understand how competitive-programming platform ratings work.

## Tools / Platforms

- CodeChef or Codeforces — contest participation and rating
- GeeksforGeeks — additional programming practice

## Preparation

Before participating in the contest:

1. Create or log in to a CodeChef or Codeforces account.
2. Open the contest section.
3. Select an appropriate upcoming contest or use a virtual contest if permitted by the activity instructions.
4. Register for the contest.
5. Review basic topics such as arrays, strings, sorting, searching, stacks, and basic algorithms.
6. Practice problems on GeeksforGeeks before the contest.

## Contest Participation

During the contest:

1. Read the complete problem statement before coding.
2. Check input and output requirements.
3. Start with problems that are easiest to understand.
4. Submit solutions through the contest platform.
5. Check the verdict after each submission.
6. Keep track of solved and attempted problems.
7. Observe the contest ranking and score.

## Rating Understanding

A competitive-programming rating is a numerical value used by a platform to represent a participant's contest performance. The exact rating calculation differs between platforms.

In general, contest performance can be affected by factors such as:

- Number of problems solved
- Correctness of submissions
- Penalties or submission time, where applicable
- Contest ranking
- Performance relative to other participants
- The participant's previous rating

The exact rating change should be recorded from the platform's official contest result after the contest.

## What I Learned

1. Coding contests require solving programming problems under time constraints.
2. Reading the problem statement carefully is important before implementation.
3. Efficient algorithms can make a significant difference when input sizes are large.
4. Contest rankings depend on performance during the contest.
5. Platform ratings provide a way to track competitive-programming performance over multiple contests.
6. A rating should be interpreted in the context of the platform and its rating system.

## Reflection

This activity helps me understand the difference between normal programming practice and competitive programming. In a contest, I need to manage time, select suitable problems, test solutions, and submit them efficiently. Tracking my rating after contests will help me monitor my progress.
